# Linux Notes

My notes from learning Linux for ethical hacking, practiced on Kali Linux in WSL2. The SSH examples use `localhost`, because a real two-machine SSH lab needs two VMs. For educational use only.

## Contents

1. [Basics and files](01-basics-and-files.md): setup, getting help, navigating files, important directories
2. [Searching and text processing](02-searching-and-text.md): find, grep, pipes, redirection, chaining commands
3. [Users and permissions](03-users-and-permissions.md): chmod, chown, sudo, SUID
4. [SSH and networking](04-ssh-and-networking.md): SSH, scp, basic networking commands
5. [Processes, services and cron](05-processes-services-cron.md): processes, systemctl, cron, signals
6. [Packages and logs](06-packages-and-logs.md): apt, repositories, log files
7. [Shell and scripting](07-shell-and-scripting.md): shell basics, PATH, scripts, nano and Vim, archives
8. [System, boot, disks and file systems](08-system-and-disks.md): system info, boot process, disks, filesystems
9. [Practice exercises](09-practice-exercises.md): 24 exercises, one for each topic
10. [Practice solutions](10-practice-solutions.md): answers to the 24 exercises
